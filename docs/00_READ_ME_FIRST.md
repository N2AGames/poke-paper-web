## 🔧 CONFIGURACIÓN NECESARIA

### Paso 1: Supabase (15 min)
```
1. Ve a https://supabase.com
2. Crea proyecto
3. Ejecuta SQL de LEADERBOARD_SETUP.md
4. Copia URL y Anon Key
```

### Paso 2: Google OAuth (5 min)
```
1. Ve a Google Cloud Console
2. Crear OAuth app
3. Copiar Client ID y Secret
4. Configurar en Supabase
```

### Paso 3: Aplicación (5 min)
```
1. Edita: src/app/modules/shared/config/supabase.config.ts
2. Pega: URL y Anon Key
3. npm start
```

**Total: 25 minutos ⏱️**
