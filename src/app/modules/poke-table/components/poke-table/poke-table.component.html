How to Play

PokeTable is a type-based Pokémon guessing game. Fill every cell in the grid with a valid Pokémon.

Each cell sits at the intersection of a row type and a column type. The Pokémon you enter must have both those types.

Click a cell to select it, then type the Pokémon's name in the search box below and select it from the list.

Complete all rows and columns to win!
